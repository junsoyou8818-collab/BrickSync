Setup Guide
BrickSync.exe 실행 및 기본 설정
🖱️ 실행: BrickSync.exe를 더블클릭하면 로컬 브릿지 서버가 자동으로 시작되고, Chrome 또는 Edge 브라우저에서 BrickSync 웹앱이 자동으로 열립니다.
🌐 브라우저 요구사항: Web Bluetooth API를 지원하는 Chrome 또는 Edge 브라우저가 필요합니다. (Firefox · Safari 미지원)
🔵 허브 연결: 웹앱이 열리면 시스템 연결 메뉴에서 레고 허브를 블루투스로 연결할 수 있습니다.
👤 계정 로그인: 학생 · 교사 · 학부모 계정으로 로그인하면 역할에 맞는 대시보드와 기능이 활성화됩니다.
별도 설치 불필요 · 원클릭 실행
📋 메뉴 기능 안내
Menu 01
홈 (Home)
BrickSync의 메인 페이지입니다.
학습 시작, 포트나이트 맵 접속, 내 프로젝트 확인 등
BrickSync의 모든 기능을 한눈에 볼 수 있는 시작 화면입니다.
시작 화면
Menu 02
학습단원 (Lessons)
BrickSync 코딩 커리큘럼 1~5단원을 학습하는 공간입니다.
단원별 미션을 수행하며 레고 허브 블록 코딩을 단계적으로 배울 수 있습니다.
각 단원을 완료하면 코인 보상이 지급됩니다.
1단원 ~ 5단원
Menu 03
AI 학습단원 (AI Lessons)
인공지능을 활용한 심화 학습 공간입니다.
6~8단원에서는 손 제스처 인식, 음성 명령 등
AI 기술과 레고 허브를 융합한 특별한 코딩 미션을 경험할 수 있습니다.
6단원 ~ 8단원 · AI 융합
Menu 04
시스템 연결 (System Connection)
레고 허브를 블루투스로 연결하고 직접 코딩하는 공간입니다.
허브의 센서 값, 모터 상태 등 실시간 작동 상태를 확인하며
블록 코드를 직접 만들고 실행할 수 있습니다.
허브 연결 · 코딩 실습
Menu 05
프로젝트 (Projects)
내가 만든 코딩 프로젝트를 저장하고 관리하는 공간입니다.
이전에 작업한 코드를 불러오거나
새 프로젝트를 시작할 수 있습니다.
프로젝트 저장 · 관리
