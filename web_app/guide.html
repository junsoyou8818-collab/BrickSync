⚙️ BrickSync 시작 가이드 (Quick Start)
Visual Step-by-Step Guide
BrickSync 시작하기 & 연동 가이드
Step 1 BrickSync.exe 다운로드 & 실행
  • legofortnite.bricksync.org ↗ 공식 웹사이트에서 BrickSync.exe 파일을 다운로드하여 실행합니다.
  • 웹사이트의 'Quick Start' 안내 가이드를 확인하며 손쉽게 시작할 수 있습니다.
  • BrickSync.exe 실행 시 로컬 브릿지 서버가 자동으로 시작되며 브라우저가 열립니다.
Step 2 2. 학생 & 교사 & 학부모 로그인 및 계정 생성
  • 학생은 계정 등록 후 학습시 학습 데이터가 클라우드 DB에 저장
  • 교사 계정으로 관리학생 및 클래스별 학습 DB 관리 및 전송
  • 학부모의 자녀 학습 데이터 실시간 수신 및 피드백
  • 계정 생성 없이도 게스트로 즉시 체험 가능
Step 3 레고 모델 조립
  • 레고 브릭을 조립하고 허브(블루투스 장치)에 모터, 컬러 센서, 라이트 등 상호작용 부품을 연결합니다.
  • 허브는 블루투스 무선 연결을 통해 각 전자 부품의 회전 및 점등을 정밀하게 제어합니다.
Step 4 학습단원 & AI 단원 선택
  • 일반 단원 (1~5단원): 보트, 잠수함, 관람차, 자동차, 사이렌 등 기초 블록 코딩 미션
  • AI 학습단원 (6~8단원): 가위바위보 지붕, 음성 마이크 그네, 몬스터 경보 등 AI 심화 미션
Step 5 레고 허브 연결 (블루투스 / USB)
  • 상단 [허브 연결 🔗] 버튼을 누르고 레고 허브 전원 버튼을 눌러 블루투스로 페어링합니다.
  • 한 번 연결된 블루투스 세션은 단원을 이동하더라도 자동으로 안정적으로 유지됩니다.
  • 블루투스 외에 USB 유선 케이블 연결도 완벽하게 지원합니다.
Step 6 6. 아이콘 · 워드 블록 코딩 & Verse 코드 변환 학습
  • [과제 확인 / Try Mission] 버튼을 클릭하여 레고 포트나이트 미션 과제를 확인합니다.
  • 하단 트레이에서 아이콘 블록들을 조립하여 레고 허브와 포트나이트를 제어하는 코드를 완성합니다.
  • 블록 코드를 Verse 코드로 1:1 변환 학습
Step 7 AI 머신러닝 / LLM 기반 바이브 코딩 학습
  • 웹캠과 마이크를 통해 손 제스처(가위/바위/보), 음성 명령, 사물(몬스터 브릭) 인식 모델을 직접 학습시킵니다.
  • 브릭싱크 웹 내에서 머신러닝 모델의 실시간 예측과 판정을 즉각 체험할 수 있습니다.
  • LLM 기반 바이브 코딩 AI 모델
Step 8 포트나이트 'The Brick Island' 맵 접속
  • 브릭싱크 웹의 중앙 버튼을 클릭하여 에픽게임즈 런처 및 포트나이트를 실행합니다.
  • 포트나이트 검색(디스커버)에서 'The Brick Island' 또는 맵 코드 7603-2493-0825를 입력하여 입장합니다.
Step 9 실물 허브 & 포트나이트 실시간 동시 연동
  • 블록 코딩 명령을 실행하여 레고 스파이크 키트와 포트나이트 3D 에셋을 실시간 동시 제어합니다.
  • 1~5단원: Run ▶ 버튼을 눌러 레고 허브와 포트나이트에 조종 신호를 전송합니다.
  • AI 6~8단원: Run 버튼 없이도 비전(제스처/사물) 및 자연어 음성/텍스트 프롬프팅으로 자동 명령이 발동됩니다.

🎮 포트나이트 플레이 환경설정
포트나이트 조작법 설정
The Brick Island 맵 키보드 조작법 커스텀 설정
포트나이트 The Brick Island 맵 접속 후, 블록 코드를 통해 에셋과 상호작용(탑승) 및 이동 조종이 작동하도록 아래 단계별로 키보드 커스텀 키를 설정해 주세요.
STEP 1
플레이어 메뉴 (ESC) → 설정
포트나이트 맵 접속 후 ESC 키를 눌러 플레이어 메뉴를 열고, 좌측 하단의 설정 (⚙️) 메뉴를 클릭합니다.
STEP 2
키보드 조작법
상단 설정 메뉴의 탭 아이콘 중 키보드 모양의 키보드 조작법 (⌨️) 탭을 선택합니다.
STEP 3
크리에이티브 입력 동작 커스텀 키 설정
스크롤을 내려 크리에이티브 입력 동작 섹션의 사용자 지정 입력 6 ~ 10, 15 ~ 17 항목을 지정된 단축키로 변경합니다.
🔑 필수 커스텀 입력 키 설정 목록 (사용자 지정 입력 6 ~ 10, 15 ~ 17)
사용자 지정 입력 6 (Interact) 에셋 상호작용 및 탑승
→ E
사용자 지정 입력 7 (Forward) 전진 이동
→ Y
사용자 지정 입력 8 (Backwards) 후진 이동
→ L
사용자 지정 입력 9 (Left) 좌회전 (왼쪽 회전)
→ U
사용자 지정 입력 10 (Right) 우회전 (오른쪽 회전)
→ O
사용자 지정 입력 15 (Rotate CW) 시계방향 회전 (오른쪽으로)
→ H
사용자 지정 입력 16 (Rotate CCW) 반시계방향 회전 (왼쪽으로)
→ J
사용자 지정 입력 17 (Stop) 회전 멈춤
→ K
